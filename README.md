## 💡 Key Interview Frameworks

### STAR Method (Behavioral Questions)
- **S**ituation: Set the stage
- **T**ask: What was your responsibility?
- **A**ction: What did YOU specifically do?
- **R**esult: What happened? Quantify if possible

### STAR-P for Coding Problems
- **S**ituation / Understand: Read and clarify requirements
- **T**hink: Discuss approach out loud
- **A**pproach / Code: Write clean, readable code
- **R**un / Review: Test with examples
- **P**ptimize: Improve time/space complexity

### RESHADED for System Design
- **R**equirements: Clarify functional & non-functional requirements
- **E**stimation: Back-of-envelope calculations
- **S**ystem: High-level architecture
- **H**igh-level: Draw diagrams with components
- **A**PI: Define key APIs/contracts
- **D**atabase: Design schema with indexes
- **E**volution: Discuss scaling strategies
- **D**eep-dive: Go deeper into 1-2 areas

### VERIFY-JUDGE-ADAPT (AI Tools)
- **V**erify: Understand what AI generated
- **J**udge: Critically evaluate quality
- **A**dapt: Improve and customize for production

## 💬 Interview Tips

### General
- Practice out loud
- Ask clarifying questions
- Explain your thinking
- Be honest about what you don't know
- Show willingness to learn

### Technical Rounds
- Start with simple approaches
- Optimize only after it works
- Test with examples
- Consider edge cases
- Discuss trade-offs

### Behavioral Rounds
- Use specific examples
- Quantify results where possible
- Show growth and learning
- Be authentic and genuine
- Ask thoughtful questions

### System Design
- Ask questions first
- Don't jump to solutions
- Draw diagrams
- Discuss trade-offs explicitly
- Mention monitoring and operations
